# 聊天会话

在 Paseo 的项目选择器里加一个当作草稿纸用的项目。选中它新建会话时，插件会在你指定的根目录下创建一个新的子目录，会话就在那个目录里跑。适合临时提问、写点脚本、试提示词，不用把文件落地到真正的仓库里。

## 工作方式

插件把根目录（默认 `~/.PaseoChats`）注册为一个 Paseo 项目并命名。在新建会话界面选中该项目后，Paseo 会请求在这个目录创建 workspace，插件把这个请求改写到 `chat-<年月日>-<时分秒>-<随机>` 子目录，于是每次新建会话都有自己的目录。所有会话目录仍然归在同一个项目下，侧边栏不会堆出一堆项目。

会话目录默认是空的，也不是 git 仓库，所以不会产生 diff 或分支噪音。

## 设置

设置 → 插件 → 本插件：

- 根目录：会话目录放在哪里，支持 `~` 开头。
- 项目名称：项目选择器里显示的名字。
- 自动清理空的旧目录：删除一周前创建、至今仍为空的会话目录，一周内动过的不会动。
- 注册为 Paseo 项目：目录存在但项目列表里看不到时手动补注册。
- 按语言重置项目名：按当前 App 语言把项目名改回 `Chat` 或 `聊天`。

界面文案跟着 App 语言走；项目名不跟随。它是 daemon 存下来的数据，所有客户端和 CLI 看到的是同一个字符串，写进去就固定了。用另一种语言打开设置页不会自动改名，只有你点那一行「重置」才会改。

## 权限与限制

插件在 daemon 机器上以你的权限运行。它会创建根目录下的子目录、删除为空的旧目录，并调用 `paseo project` 注册或重命名项目。它不读取会话内容，不联网，也不写插件自己创建的目录之外的路径。

改写 workspace 创建请求依赖 daemon 提供的 `workspace.create.before` 钩子。在已有的聊天 workspace 里再加会话仍然共用那个目录；只有从项目选择器新建会话才会创建新目录。
