# Claude 默认主题

Paseo 主题插件，将界面调整为 Claude 风格的暖中性浅色配色。

## 配色基准

| Token | Hex | 用途 |
|---|---|---|
| background | `#F7F6F2` | 页面背景 |
| foreground | `#2C2C2A` | 主文字 |
| raised | `#FFFFFF` | 卡片与抬升层 |
| control | `#EFEEE9` | 控件背景 |
| border | `#DDDCD6` | 边框 |
| accent | `#D97757` | 强调色、焦点环 |
| mutedForeground | `#706F6A` | 次要文字 |
| ring | `#D97757` | 焦点环 |

Claude 的产品颜色会随产品、平台和版本变化。以上是面向 Paseo token 的可复现近似，不声称是 Anthropic 官方设计令牌。
